# Multi-Language & Locale Engine Skill

Provides runtime dictionary translation, currency localization, and locale-aware number formatting.

## Supported Locales:
- `pt-BR`: Português (Brasil) - Default
- `en-US`: English (United States)
- `es-ES`: Español (España / Latinoamérica)

## Supported Currencies:
- `BRL`: Real Brasileiro (R$)
- `USD`: US Dollar ($)
- `EUR`: Euro (€)
