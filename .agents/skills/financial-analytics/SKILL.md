# Financial Analytics Skill

This skill provides expert financial diagnostic algorithms and analytics runbooks for PlannerFin.

## Capabilities:
1. **Cash Flow & Burn Rate Analysis**:
   - Calculates operational monthly cash flow: `Receitas - Despesas Fixas - Despesas Variáveis`.
   - Projects runway and savings rate percentage: `((Receitas - Despesas) / Receitas) * 100`.

2. **50/30/20 Budget Optimization**:
   - Compares actual user expenses against ideal allocations (50% Necessidades, 30% Estilo de Vida, 20% Investimentos/Quitação).

3. **Compound Interest & Wealth Projection**:
   - Formula: `M = P * (1 + i)^t + PMT * [((1 + i)^t - 1) / i]`.
