# UI Theme & Appearance Customizer Skill

This skill governs the appearance, visual themes, color palettes, and component geometry across the entire PlannerFin application.

## Capabilities:
1. **Theme Presets**:
   - `mobills-dark`: Mobills authentic dark mode (#1C1C1E bg, #2C2C2E surfaces).
   - `midnight-oled`: Pure black for OLED displays (#000000 bg, #121212 surfaces).
   - `emerald-slate`: Deep navy teal (#0B132B bg, #1C2541 surfaces).
   - `clean-light`: Crisp modern white (#F8FAFC bg, #FFFFFF surfaces).
   - `warm-sand`: Soft eye-friendly parchment (#FBF9F5 bg, #FFFFFF surfaces).
2. **Accent Colors**:
   - Mobills Indigo/Purple (`#7C4DFF`)
   - Mobills Emerald (`#00A884`)
   - Ocean Blue (`#0091FF`)
   - Sunset Amber (`#FF8A00`)
   - Neon Pink (`#EC4899`)
3. **Corner Geometry**:
   - Ultra-Rounded (25px - Mobills standard)
   - Smooth (16px)
   - Crisp (8px)
